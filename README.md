# Cos 209 assignment

1. 
Classes:
Classes are like a plan or design for making objects. It’s like saying “all cars must have a brand, year and can drive.” Then from that plan you can create many cars.
2. 
Arrow Functions:
This is just a shorter way to write functions in JavaScript. Instead of writing the long function, you just use =>. People use it a lot because it’s faster to type.
3. 
Variables:
Variables are like containers where we keep data.

var = old way (we don’t really use it now)

let = can change later

const = cannot change once you set it
4. 
Array Methods:
Arrays have special tools that make life easier.

map → changes every item in the array into something new

filter → picks only some items from the array

reduce → adds or combines everything into one result

forEach → just goes through each item one by one
5. 
Destructuring:
This is like unpacking. Instead of going to get values one by one, you just pull them out at once from an array or object.
6. 
Modules:
Modules are just when you break your code into different files. One file can export (share) something and another file can import (use) it. It helps to keep big projects neat.

7. 
Ternary Operators:
This is a short way of writing if else. It’s just one line: if something is true do this, otherwise do that.

8. 
Spread Operators:
The three dots ... that help you copy or join things. You can use it to join arrays together or combine objects.
